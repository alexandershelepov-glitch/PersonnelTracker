# Учёт личного состава — версия 0.5.1 для macOS

Запустите `start_mac.command` двойным щелчком. При первом запуске нужен интернет для установки PySide6. Если запуск завершился ошибкой, полный текст сохранён в `data/logs/launch.log`.

## Главное в 0.4

- Добавлен экран **«Штат и личный состав»**: штатные единицы существуют независимо от работников, а незанятая единица показывается как **ВАКАНСИЯ**.
- Работник и штатная единица используют фиксированные отделения: «Руководство», «1 отделение», «2 отделение». Для данных после миграции используется нейтральное «Не указано» до ручного распределения.
- Экран штата фильтруется по отделению, ищет ФИО/табельный номер/должность/отделение, сортируется по заголовкам и открывает карточку или единицу двойным щелчком.
- В карточке добавлены отделение и служебный блок. Несохранённые изменения предлагается сохранить перед действиями с фото и журналами, а при закрытии карточки отображается предупреждение.
- Верх расхода теперь считает по штатным единицам: по штату, по списку, вакантно, отсутствуют, на лицо. Алгоритм событий и графика 1/3 сохранён.

## Миграция 0.3 → 0.4

Приложение всегда использует одну базу: `data/personnel.db` рядом с `app.py`. При запуске её абсолютный путь выводится в журнал запуска. Миграция выполняется автоматически и не удаляет работников, фотографии, проверки, обучение, оружие и события. Для каждого существующего работника создаётся отдельная штатная единица `М-<ID>`; её можно затем отредактировать. Файлы фото остаются в `data/photos`, в БД хранится относительный путь.

Для пустой тестовой базы в меню «Сервис» доступна команда «Добавить демо-данные». Она создаёт единый набор из четырёх работников, четырёх штатных единиц и двух событий; повторно поверх существующих данных команда не выполняется.

## Резервная копия

При закрытой программе копируйте всю папку `data/`: в ней находятся `personnel.db` и `photos/`.
