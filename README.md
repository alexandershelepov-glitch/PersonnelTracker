# Учёт личного состава — PersonnelTracker

Запустите `start_mac.command` двойным щелчком. При первом запуске нужен интернет для установки PySide6. Если запуск завершился ошибкой, полный текст сохранён в `data/logs/launch.log`.

## Текущее состояние

Ветка `main` содержит принятую версию v0.6. Разработка v0.7 ведётся в `feature/v0.7-data` и включает защиту данных, CSV-обмен и далее удалённое хранение резервных копий.

Приложение использует одну локальную SQLite-базу `data/personnel.db`. Фотографии работников находятся в `data/photos/`, а в базе хранятся относительные пути к ним.

## Резервные копии — v0.7.1

На странице **«Сервис»** доступны команды:

- **«Создать резервную копию»** — формирует ZIP-архив с согласованным снимком SQLite и всеми фотографиями;
- **«Восстановить из копии»** — сначала проверяет ZIP, целостность SQLite, обязательные таблицы и версию схемы, и только после этого заменяет рабочие данные;
- перед каждым восстановлением автоматически создаётся отдельная страховочная копия текущего состояния;
- один раз в день при запуске создаётся автоматическая локальная копия; хранятся семь последних автоматических копий.

По умолчанию автоматические и страховочные копии находятся в `data/backups/`. Ручную копию можно сохранить в выбранное пользователем место.

Резервный ZIP содержит:

- `manifest.json` — сведения о формате, времени создания и версии схемы;
- `database/personnel.db` — согласованный SQLite-снимок;
- `photos/` — фотографии работников.

Приложение не использует резервный ZIP как рабочую базу. В дальнейшем Google Drive должен применяться как место хранения готовых резервных копий, а рабочая SQLite-база останется локальной.

## CSV — v0.7.2

На странице **«Сервис»** добавлен блок **«Импорт / экспорт CSV»**.

Импорт работников выполняется по безопасной схеме:

1. CSV сначала только читается — база не меняется.
2. Показывается предпросмотр строк со статусами **«Готово»**, **«Проверить»** и **«Ошибка»**.
3. Проверяются обязательные поля ФИО и табельный номер, даты, график и повторы табельных номеров.
4. Совпадение табельного номера с существующей записью блокирует строку; совпадение ФИО с другим табельным номером показывается как возможный дубликат и требует ручного выбора.
5. Перед фактическим импортом автоматически создаётся страховочная резервная копия `pre-import`.
6. Выбранные строки вставляются одной транзакцией: при ошибке операция откатывается целиком.
7. Импорт не создаёт и не занимает штатные единицы автоматически. Новые работники остаются в списке не назначенных на ШЕ до явного назначения пользователем.

Поддерживаются CSV в UTF-8/UTF-8 BOM и Windows-1251, разделители `;`, `,` и табуляция. Даты распознаются в форматах `ДД.ММ.ГГГГ`, `ДД/ММ/ГГГГ`, `ДД-ММ-ГГГГ` и `ГГГГ-ММ-ДД`.

Распознаются основные колонки карточки: ФИО, табельный номер, отдел, отделение, группа, должность, дата рождения, телефон, E-mail, фактический адрес, адрес регистрации, дата приёма, график, дата рабочей смены, образование и номер удостоверения. Лишние колонки не импортируются и перечисляются в предпросмотре.

Экспорт выгружает действующий личный состав в CSV с разделителем `;` и UTF-8 BOM для удобного открытия в Excel. Для работников, назначенных на штатные единицы, организационные поля берутся из актуальной ШЕ.

## Миграции данных

Миграции выполняются автоматически при запуске и не должны удалять работников, фотографии, проверки, обучение, оружие и события. Текущая версия схемы хранится в таблице `settings`.

## Демо-данные

Для пустой тестовой базы в меню и на странице «Сервис» доступна команда **«Добавить демо-данные»**. Повторное добавление поверх существующих данных запрещено.

## Тесты

```bash
source .venv/bin/activate
python -m unittest discover -s tests -v
```

Для v0.7.1 используется `tests/test_backup.py`: создание копии, восстановление базы и фотографий, отказ от повреждённого ZIP, защита от небезопасных путей и ежедневное автокопирование.

Для v0.7.2 добавлен `tests/test_csv_data.py`: распознавание русских заголовков и дат, Windows-1251, обработка дубликатов, транзакционный импорт без автоматического создания ШЕ и Excel-совместимый экспорт.

GUI smoke-тест запускается отдельно:

```bash
.venv/bin/python tests/smoke_gui.py
```
